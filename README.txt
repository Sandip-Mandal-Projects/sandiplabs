SANDIP LAB — STATIC WEBSITE
===========================

Files:
- index.html: complete responsive website (HTML, CSS, JavaScript in one file)

LOCAL PREVIEW
1. Extract this ZIP.
2. Open index.html in a modern browser.
3. SHA-256 tool works on HTTPS or localhost (some browsers restrict Web Crypto on file://).
4. QR generator uses api.qrserver.com and sends the entered text/URL to that service. Do not submit sensitive data.

DEPLOY TO VERCEL
1. Create a new project in Vercel and import a Git repository containing index.html,
   OR use Vercel's static deployment workflow.
2. No build command is required for this plain HTML version.
3. Set the output/root directory to the folder containing index.html.
4. Assign sandip.vercel.app in Vercel project settings if it is available to your account.
